اعضا: امیرحسین قادری - فاطمه یعقوبی - غزال تاجگر

مسئله پروژه : سیستم حل مشکلات شهروند های راننده در تهران. رانندگان مکررا در طول شبانه روز از مسیر های شهری اعم از خیابان ها، کوچه ها، اتوبان ها و ... استفاده میکنند. لذا مسیر ها همواره نیاز به تعمیر و نگهداری دارند. تا در صورت استهلاک، مشکلات متعدد در تردد شهری رخ نداده، سرعت حمل و نقل افت نکرده، از بروز سوانح جلوگیری شود.
