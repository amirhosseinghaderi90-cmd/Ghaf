# ثبت عنوان شکایت

## User Story

به عنوان یک کارمند، می‌خواهم بتوانم عنوان مسئله خود را در سامانه ثبت کنم تا بتوانم مشکلات و شکایت‌های خود را به‌صورت مشخص ثبت کنم.

## توضیحات

سامانه باید امکان وارد کردن عنوان برای شکایت را در اختیار کارمند قرار دهد.

## معیارهای پذیرش (Acceptance Criteria)

1. کارمند باید بتواند عنوان شکایت را وارد کند.
2. فیلد عنوان نباید خالی باشد.
3. عنوان واردشده باید هنگام ثبت شکایت ذخیره شود.
4. در صورت خالی بودن عنوان، سامانه باید پیام خطای مناسب نمایش دهد.
